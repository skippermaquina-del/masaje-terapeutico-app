# Muscles of Leg, Ankle & Foot

## Posterior (Plantarflexors)
- Gastrocnemius: plantarflex + knee flex (2 joints)
- Soleus: plantarflex only
- Flexor digitorum longus / hallucis longus
- Tibialis posterior: inverts + plantarflexes

## Anterior/Lateral (Dorsiflexors & Evertors)
- Tibialis anterior: dorsiflex + invert
- Extensor digitorum/hallucis longus: dorsiflex assist
- Peroneus longus/brevis: evert + plantarflex assist

## Functional Stirrup
- Tibialis anterior + peroneus longus -> near same insertion, opposite actions

## Movement Summary
- Plantarflexion: gastroc, soleus (main)
- Dorsiflexion: tibialis anterior (main)
- Inversion: tibialis anterior + posterior
- Eversion: peroneus longus + brevis

## Clinical
- Drop foot -> tibialis anterior/nerve issue
- Inversion sprain -> strengthen peroneals
- Achilles issues -> gastroc + soleus (test knee bent vs straight)
