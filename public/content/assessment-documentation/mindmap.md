# Assessment & Documentation

## Assessment is Ongoing
- Not just intake
- Continuous through session

## Intake Vocabulary
- Subjective vs Objective data
- Chief complaint
- Red flag
- Medical referral

## Palpation & Observation
- Tissue texture/tone/temperature
- Edema, Guarding
- Symmetry/asymmetry
- Hyper/hypotonicity
- Guides technique, never diagnoses

## Treatment Planning
- Client-centered goals
- Session pacing
- Pressure modification
- Reassessment
- Discomfort -> adjust, not push through

## SOAP Notes
- S: Subjective
- O: Objective
- A: Assessment (within scope)
- P: Plan

## Documentation Rules
- Factual, no opinions
- If not written, didn't happen
- Confidential, retained per regulation

## Exam Scenarios
- New numbness -> pause, refer
- Sharp pain -> reduce pressure, reassess
- Medication question -> refer to physician
- Undiagnosed lesions -> avoid area, hygiene protocol
