# Joint Classification

## Structural Types
- Fibrous: dense CT, no cavity (sutures) -> synarthrosis
  - Exception: radioulnar/tibiofibular -> amphiarthrosis
- Cartilaginous: cartilage (discs, pubic symphysis) -> amphiarthrosis
- Synovial: fluid cavity, capsule -> diarthrosis

## Functional Types
- Synarthrosis: immovable
- Amphiarthrosis: slightly movable
- Diarthrosis: freely movable

## Six Synovial Joint Types
- Ball-and-socket: all planes (shoulder, hip) - most mobile
- Condyloid: flex/ext, abd/add, no rotation (wrist, MCP)
- Saddle: multiple planes (thumb CMC)
- Hinge: flex/ext only (elbow, knee)
- Pivot: single-axis rotation (atlantoaxial, proximal radioulnar)
- Gliding: short slide/twist (carpals, SI joint)

## Clinical Relevance
- Joint type predicts expected ROM
- Hinge -> only check flex/ext
- Ball-and-socket -> full assessment needed
