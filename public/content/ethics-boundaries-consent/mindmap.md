# Ethics, Boundaries & Consent

## Core Principles
- Autonomy
- Beneficence
- Nonmaleficence
- Justice
- Veracity
- Fidelity

## Informed Consent
- Ongoing, not one-time
- Re-establish if technique/area/pressure changes
- Can be withdrawn anytime

## Professional Boundaries
- Power differential (therapist responsible)
- Boundary crossing vs violation
- Transference / countertransference
- Romantic-sexual contact = always unethical

## Dual Relationships
- Multiple roles -> conflict of interest
- Test: benefits therapist more than client? -> risk
- Gifts/favors: approach cautiously

## Scope of Practice
- Defined by law, not training
- No diagnosing, no medical advice
- Explain limits + refer when outside scope

## Mandatory Reporting
- Abuse / neglect / imminent harm
- Overrides confidentiality

## Documentation
- SOAP: Subjective, Objective, Assessment, Plan
- Factual, no personal opinions
- Legal safeguard

## Decision Order
- 1. Safety
- 2. Scope
- 3. Consent
- 4. Boundaries
- 5. Client benefit
